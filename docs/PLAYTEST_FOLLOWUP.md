# 플레이 피드백 후속 수정과 실행·발표 자료

2026-11-15. 사용자 실제 플레이 피드백을 반영한다. 기준 main `f27da71`. 이 문서의 지도 단축키와 창 닫기 규칙은 이전 URGENT_FIELD_INTERACTION의 Esc 설명보다 우선한다. NASA v0.3 규칙과 현장 건설 권한은 유지한다.

## 사용 흐름

| 입력 | 동작 |
| --- | --- |
| 현장 1 | 같은 위치의 설치·철거 메뉴 |
| 현장 2 또는 E | 읽기 전용 상세 |
| 현장 3 | 해당 칸 3D 관찰 |
| 탐색 중 4 / 기지 지도 버튼 | 어디서든 5×5 설치 현황 조회 |
| 중앙 단말기 2 또는 E | 사건·통신·턴·되감기를 포함한 기지 운영 대시보드 |
| 현장 창·중앙 대시보드·기지 지도에서 Esc / 닫기 | 시작 안내를 반복하지 않고 탐색으로 복귀 |
| 도움말·3D 관찰에서 Esc | 열기 전 화면으로 복귀 |
| 탐색 중 Esc / 포커스 상실 | 짧은 일시정지 화면. 자동 이동/마우스 잠금 재개 없음 |

기지 지도에는 시설과 빈 칸, 설치·철거 예정 상태를 구분한다. 지도 조회나 지도에서의 3D 관찰로 건설·철거·턴·통신·되감기를 실행하지 않는다. 건설은 실제 4m 안의 동일 현장을 바라볼 때만 허용한다.

캡처 모드는 사용자 닫기·재개 입력에서 복구한다. 브라우저의 포인터 잠금이 거절되면 드래그 탐색을 사용한다. 포커스가 돌아왔다는 이유만으로 자동 잠금을 요청하지 않는다.

## 로컬 실행 범위

Windows 10/11 x64에서 RUN_GAME.cmd를 더블클릭하면 프로젝트 내부 Godot를 재사용하거나 공식 고정 버전을 내려받아 SHA256 확인 후 설치한다. 전역 PATH나 관리자 설치를 요구하지 않는다. 첫 다운로드에는 인터넷이 필요하다. 게임은 NASA 내장 보관 자료로도 실행할 수 있다. Git·Blender·Python·Web export templates는 로컬 플레이의 필수 요소가 아니다.

다른 OS는 자동 설치 지원을 주장하지 않으며 Godot 일반판으로 project.godot를 여는 기존 경로를 안내한다.

## 발표 및 이슈 완료선

발표 자료는 실제 구현 화면·NASA DONKI FLR/SEP/CME의 게임 연결·되감기 비교·실행 방법을 포함한다. 대상은 7~12세지만 실제 아동 사용성이나 학습 효과를 검증했다고 주장하지 않는다. 관측 자료와 교육용 전력/통신 규칙을 구분한다.

#71/#72/#73은 각 구현/자료와 핵심 검증을 마치고 main에 반영한 뒤 종료한다. #47의 남은 사용자 검증은 #29에 모아 중복 추적을 줄인다. #7은 발표 자료 준비만 재개하며 영상·외부 공개·실제 접수 완료로 처리하지 않는다. 사용자/아동·Web/iframe 등 미실행 확인은 근거 없이 체크하지 않는다.
