# 긴급 픽스: 1인칭 몸체와 현장 조작

2026-11-15. 사용자 요청에 따른 변경 계약이며 과거 중앙 단말기 건설·현장 E 편집 설명보다 우선한다. NASA 자료/교육용 계산 규칙 v0.3은 유지한다. PPT·영상·배포는 이번 범위에 포함하지 않는다.

## 조작과 권한

| 위치 / 키 | 동작 | 변경 가능 범위 |
| --- | --- | --- |
| 가까운 빈 부지·시설 / 1 | 설치·철거 메뉴 | 현재 바라보는 그 위치만 |
| 가까운 빈 부지·시설 / 2 또는 E | 현장 상세 | 읽기 전용 |
| 가까운 빈 부지·시설 / 3 | 3D 관찰 | 읽기 전용, 이전 화면으로 복귀 |
| 중앙 운영단말기 / 2 또는 E | 기지 대시보드 | 상태·격자·예상·사건·통신·턴·되감기 |
| Esc | 메뉴 닫기 / 관찰 종료 | 조작 재개는 기존 시작 버튼/화면 클릭 |

- 1은 메뉴만 연다. 시설 유형 선택 후 명시적인 설치 또는 철거 버튼을 눌러야 바뀐다.
- 시선에서 처음 닿은 부지·시설이 4m 이내인 경우만 조작한다. 다른 시설이나 벽이 가리면 접근할 수 없다.
- 메뉴를 연 뒤에도 적용 순간 같은 위치·거리·시선을 다시 검사한다. 오래된 메뉴, 다른 칸 번호, 상세 화면, 3D 화면, 중앙 대시보드의 요청으로는 건설할 수 없다.
- 중앙 격자 선택은 정보와 3D 확인용이다. 시설 종류 선택·설치·철거·전체 배치 취소는 제거한다. 질문 예약은 통신 토글로 취소한다.
- 고정 거주실은 철거할 수 없다. 예산·환급·시설 효과·NASA 계산은 기존 규칙을 따른다.
- 현장에서 만든 배치는 즉시 장면에 반영하는 미확정 배치다. 중앙 대시보드의 턴 진행으로 자원과 턴을 확정한다. 되감기는 기존처럼 당시 전체 상태를 복원하는 별도 훈련 기능이다.

## 화면과 몸체

- 부지 모서리/건물 외곽을 강조하고 작은 네모 카드 3개에 키와 짧은 행동 이름을 표시한다. 중앙 단말기는 대시보드 카드만 표시한다.
- 현장 창은 한 칸만 보여 준다. 4종 시설 선택, 비용·효과, 설치/철거, 자원 막대를 제공하고 다른 칸으로 옮기는 지도를 넣지 않는다.
- 1인칭 몸통·허리·어깨·팔·손·다리가 연결되어 보인다. 시점에 따라 팔 전체를 숨기지 않는다. 벽 앞에서는 팔을 접고 시선 제한과 기존 충돌·점프를 유지한다.
